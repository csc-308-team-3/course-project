# ChoreMate User Stories

## Jared Moy

1. As a roommate, I want to add instructions to a chore so that everyone knows how it should be completed.

2. As a roommate, I want to receive a notification at least 24 hours before my chore is due so that I do not forget it.

3. As a roommate, I want to add roommates to my household group so that we can view the same chore responsibilities page.

4. As a roommate, I want to assign estimated completion times to chores so that I can plan my schedule.
